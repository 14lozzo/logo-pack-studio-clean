# Logo Pack Studio — Foundation V3

## Instalação
Substituir na raiz do repositório GitHub Pages os ficheiros `index.html`, `app.js`, `style.css`, `jszip.min.js` e `README.md`. Fazer commit e aguardar o deploy. Não é necessário instalar versões intermédias.

## Alterações V3
- Páginas PDF sempre com fundo de página branco, texto principal preto e detalhes dinâmicos na cor principal.
- Ao importar um logótipo, é feita uma estimativa da sua cor cromática predominante. Pode corrigir manualmente no seletor de cor.
- Botão de modo claro/escuro no cabeçalho, guardado no navegador. O tema não altera as exportações.

## Limitações
- A deteção automática de cor é heurística, especialmente em SVGs multicoloridos.
- Algumas áreas de demonstração dentro das páginas mantêm fundos coloridos intencionais.
- Verificar visualmente um PDF exportado com os materiais reais antes da entrega ao cliente.
